Aug 2022 - Present 
Memeswift is an AI-powered website that allows users to create humorous and trendy memes in seconds. Users can upload or capture images, and the tool generates the meme based on the image. It supports jpg, jpeg, and webp files. The project gained some popularity, having generated over 30,000 memes. Memeswift is a platform that harnesses the power of artificial intelligence to make meme creation accessible to a wide audience.
